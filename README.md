# Kasa
<h3>📖 Description:</h3>

- A modern, dynamic, and fully responsive website for an apartment rental company.


<h3>🚀 Demo:</h3>

- [Live Preview](https://prayeronaiwukasa-website.vercel.app/)


<h3>🛠️ Technologies:</h3>

- `React`
- `React Router`
- `Sass`
- `JavaScript (ES6+)`


<h3>💻 Functionalities:</h3>

- Interactive UI elements
- Semantic HTML
- Dynamic navigation without page reload
- Dynamic data fetching from JSON files
- CSS animations

<h3>⚙️ Installation:</h3>

To run this project locally, you can follow these steps:

1. Clone the repository:
```bash
git clone https://github.com/prayer-on/kasa-website.git
```

2. Select the Project folder:
```bash
cd kasa-website
```

3. Install the dependencies:
```bash
npm install
```

4. Start the server:
```bash
npm run start
```
